#  Simulador de Misión Galáctica

Aplicación interactiva que simula una aventura espacial donde debes gestionar recursos, cuidar a tu tripulación y alcanzar una distancia objetivo para completar la misión.


---

##  Características

- Gestión de recursos (agua, comida, energía)
- Bitácora de eventos con logging dinámico
- Estado de salud de tripulantes visual
- Eventos aleatorios espaciales
- Barra de progreso de la misión
- Modal de configuración personalizada
- Animaciones con Bootstrap + Animate.css
- Firma digital personalizada con efecto neón

---

##  Tecnologías Usadas

- HTML5
- CSS3 + Bootstrap 5
- JavaScript ES6
- Animate.css
- [Google Fonts: Orbitron](https://fonts.google.com/specimen/Orbitron)

##  Cómo usar

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` directamente en tu navegador.
3. Configura tu misión, gestiona los recursos y ¡explora el universo!
